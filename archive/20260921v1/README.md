# A股自选快照

北京时间交易时段自动分析。不代下单。

GitHub：https://github.com/will6443211/cursor

## 跑一次

```bash
python3 run_snapshot.py
```

报告在 reports/ 与 自选快照.pdf

## 自选

编辑 watchlist.json

## 仓位与风控

编辑 `risk_config.json`：

| 字段 | 含义 |
|---|---|
| capital | 总资金 |
| risk_pct | 单笔愿意亏掉总资金的百分比 |
| max_total_pct | 总仓上限 |
| max_line_pct | 单条主线仓位上限 |
| max_name_pct | 单票仓位上限 |
| max_per_line | 同一条主线最多买几只 |
| cost_pct | 双边交易成本（印花税+佣金+过户费） |

报告第 0c 节按「风险额 ÷ 止损距离」给建议股数，并挡住同主线重复下注和净盈亏比低于 1.2 的位置。

## 信号复盘（闭环）

报告第 2 节 **胜率追踪** 里两块：**胜率-今日必买**（第0节当时买了的可小仓 + 「假如当时买了」对照），**胜率-尾盘狙击**（第1节尾盘狙击可尾盘）。观察/不买/不追的胜率是对照，不是买点。都不改今天的闸。

每个交易日每只可小仓只记一次：入选日 + 入选价。盘中反复跑不追加。
盘中 09:30–14:50 入选，成交价=入选价；收盘后入选，成交价=次日开。A股 T+1，胜负看次日收相对成交价并扣成本。
尾盘狙击按第一次可尾盘记，14:30 后入选价=当时尾盘价，隔夜胜率看次日开。

## 隔夜数据

外盘报价优先新浪美股/期货（Yahoo 常 403），并每天抓新浪财经滚动作第1/2节快讯。
笔记 `macro_notes.json` 只作背景，过期会标明截止日期。

## 运行期产物

`reports/journal/`（信号留档）、`reports/gate_state.json`（判别滞后带状态）、
`reports/ztpool/`（涨停池历史缓存）、`reports/overnight_cache.json`（隔夜报价缓存）。
删掉不影响运行，但复盘样本会丢。

## 最新资讯

外盘、快讯、次日预案。报告最前一节独立目录，只盯不开仓。

## 下手钟

09:30–14:30 不是随时买。报告第 15 节，只标钟不改闸。

- 游资/早盘接力仓：优先 09:35–10:00，第二买点 10:00–10:30（10:30 再刷，均价/主线还在再动），14:30 截止。
- 趋势：更靠 10:00–10:30 回踩和 13:00–13:30 午后确认，不抢开盘三分钟。
- 尾盘狙击：14:30–14:40 只看盘，**14:40–14:55 主买**（第1节可尾盘才下），14:57 不追。次日 **09:31–09:50 冲高卖**，低开 09:30–09:35 先走，最晚 10:00 清完。
- 散户 A 股 T+1，做不到游资席位「上午买下午卖」。今天 09:35–10:30 买，明天 09:30–10:00 卖。尾盘狙击才是散户合法的尾盘买、次日早盘卖。

## 尾盘狙击

独立仓，不进「今日必买 / TOP5」，也不跟游资/趋势/早盘接力仓混闸。14:40–14:55 主买（14:30 先看盘），次日 09:31–09:50 卖，10:00 前清完。报告第 1 节。流通 50～200 亿加分；**市值 ≥400 亿硬否决**。均价下不做；近 10 日至少 1 次涨停；近 3 日资金主线才做。隔夜强势仍是 3%～5% 未涨停（换手 5%～10% 只加减分，不硬卡）。
